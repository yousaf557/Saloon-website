## 🆘 Common Questions

**Q: How do I update my WhatsApp number?**
A: Open `src/components/WhatsAppButton.tsx`, find line 18, replace `'1234567890'` with your number.

**Q: Can I customize the pricing packages?**
A: Yes! Edit the `packages` array in `src/pages/Pricing.tsx`.

**Q: How do I add my Instagram posts?**
A: Update the `instagramPosts` array in `src/sections/InstagramFeed.tsx` with your image URLs.

**Q: Will this work on mobile?**
A: Yes! All pages are fully responsive and tested.

**Q: Can I deploy to GitHub Pages?**
A: Yes! See deployment guide in ENHANCEMENT_GUIDE.md.
